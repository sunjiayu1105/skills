# 1 Skill 编写规范

拟定、修订或写入 Skill 规则时，按[Skill 编写规范](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/skill-writing-rules.md:1)执行。

# 2 Java 面试材料整理

## 2.1 独立判断与正确性核验

整理材料的各阶段均按[独立判断与正确性核验](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/independent-judgment.md:1)执行。

## 2.2 确定考点整理方式

开始整理时，先确认本次是沿用已确认的考点，还是重新梳理考点。用户已明确选择时，直接按该选择执行。

用户选择重新梳理考点时，以用户指定的文档为范围。用户尚未指定文档时，先确认本次要整理哪些文档，再核实材料并形成初稿。

1. 确定整理范围后，按[确定四类配套文档的名称和排列顺序](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/document-restructure.md:107)查找已有文件。查找时按三位编号和下划线之后的完整名称匹配。

2. 遇到旧名称时，按内容判断文件用途，将仍需保留的内容归入对应的配套文档。

   **示例** 目录中同时有《整理初稿_汇总》和《001–061整理初稿》时，以本轮初稿为主体，将正文仍在引用的依据迁入《整理初稿》。

3. 用户确认本轮问题后，用本轮已确认的问题条目替换导航中的上轮清单。答题文档确定后，更新各条目的链接。

4. 更新《面试考点_已确认规则》时，按[《面试考点_已确认规则》的记录内容](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/document-restructure.md:5)保留仍然有效的要求，并写入本轮新确认的要求。

5. 移除旧文件前，核对仍需保留的内容是否已迁入最新文件，并确认原有引用已指向迁入后的对应位置。

## 2.3 核实材料并形成初稿

确认考点整理方式后，按[核实材料并形成初稿](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/material-verification-and-draft.md:1)的规则核实材料并形成初稿，再进入考点确认。

## 2.4 确认考点

初稿形成后，按用户在[2.2 确定考点整理方式](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/SKILL.md:16)中确认的选择执行。

1. 用户选择沿用已确认的考点时，按[沿用已确认的考点](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/interview-topics.md:9)中的规则确定本次使用的清单。

2. 用户选择重新梳理考点时，先按[挖掘候选考点](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/interview-topics.md:13)中的规则，从本次材料中提取候选考点，再按[根据考点拟定问题](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/interview-topics.md:77)中的规则，逐个拟定问题，确定主问题和追问、答题范围及候选理由，核对依据后直接写入《候选问题清单》。整份清单写完并核对后，提交用户确认。

本次使用的考点和答题范围确定后，判断是否需要拆分或重组。

## 2.5 文档拆分与重组

1. 需要拆分或重组时，按[面试文档拆分与重组](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/document-restructure.md:1)提交方案。用户确认后，按细则执行拆分、同步更新引用并检查拆分结果。

2. 完成拆分检查并修正发现的问题后，进入[2.6 逐篇整理与复核](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/SKILL.md:56)，按最终文档清单逐篇检查全文。

3. 无需拆分或重组时，直接进入[2.6 逐篇整理与复核](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/SKILL.md:56)。

## 2.6 逐篇整理与复核

对最终文档清单中的每一篇文档，按[逐篇整理与复核](/C:/Users/Administrator/.codex/skills/java-interview-doc-workflow/references/per-document-revision-and-review.md:1)执行。
