# 1 Anki 卡片生成

## 1.1 适用范围

当用户要求将 Markdown 文档整理为 Anki 卡片，或明确调用本 skill 时使用。执行时直接在原 Markdown 文件上修改。

## 1.2 牌组名称

1. 根据文档所在项目根目录和相对父目录生成牌组名称，不包含盘符、绝对路径和文件名。
2. 项目根目录名称作为第一个层级；后续每级父目录依次追加，层级之间使用两个半角冒号 `::` 连接。
3. 例如文档位于 `eas/002_消费记录分库分表、双写与ES 改造（15）/001_改造原因.md`，牌组名称为：

   `eas::002_消费记录分库分表、双写与ES 改造（15）`

4. 无法确定项目根目录时，不猜测；保留待确认事项并请求用户指定根目录。

## 1.3 卡片结构

每张卡片必须按以下顺序生成，标记后的半角空格必须保留：

```text
TARGET DECK: 目标牌组
Q: 一级标题
A: 
原文档全文内容
```

1. `TARGET DECK: ` 后填写按 1.2 生成的牌组名称。
2. `Q: ` 后必须在同一行填写文档真实的一级标题文字，不包含开头的 Markdown `#` 标记。
3. `A: ` 必须紧跟在题目行之后并单独占一行，答案从下一行开始。
4. 原文档全文作为答案，从原一级标题开始按原顺序完整保留；不擅自删改、总结或补充内容。
5. `TARGET DECK: `、`Q: ` 和 `A: ` 后各保留一个半角空格。
6. 如果文档没有且只有一个明确的一级标题，暂停并说明缺少或存在多个题目，不能自行选择。

## 1.4 输出检查

生成前检查以下内容：

1. 牌组名称是否只由项目根目录和相对父目录组成。
2. `TARGET DECK: ` 是否位于卡片首行。
3. `Q: ` 后是否填写了文档真实的一级标题文字，且不包含开头的 Markdown `#` 标记。
4. `A: ` 是否紧跟在题目行之后并单独占一行。
5. 答案是否从下一行开始，并完整包含原文档全文，从原一级标题开始。
6. 是否保留了三个标记后的一个半角空格。
7. 只调整 Anki 卡片的格式，不改变原文的意思。
